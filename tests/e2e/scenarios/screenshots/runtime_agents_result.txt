│  ## 7. Design Patterns                                                                                                                                                                   ║
│                                                                                                                                                                                          ║
│  ### 7.1 **Dependency Injection via Generics**                                                                                                                                           ║
│  The `AuthenticationService` uses generic type parameters for its dependencies, allowing for:                                                                                            ║
│  - Easy testing with mock implementations                                                                                                                                                ║
│  - Flexibility to swap implementations                                                                                                                                                   ║
│  - Compile-time verification of interface compliance                                                                                                                                     ║
│                                                                                                                                                                                          ║
│  ### 7.2 **Repository Pattern**                                                                                                                                                          ║
│  The `UserRepository` trait abstracts data storage:                                                                                                                                      ║
│  - Decouples business logic from storage implementation                                                                                                                                  ║
│  - Enables in-memory testing                                                                                                                                                             ║
│  - Supports multiple backends (PostgreSQL, MongoDB, etc.)                                                                                                                                ║
│                                                                                                                                                                                          ║
│  ### 7.3 **Strategy Pattern**                                                                                                                                                            ║
│  Both `PasswordHasher` and `TokenGenerator` are traits:                                                                                                                                  ║
│  - Different hashing algorithms can be used (bcrypt, argon2, scrypt)                                                                                                                     ║
│  - Different token strategies (JWT, opaque tokens, OAuth)                                                                                                                                ║
│                                                                                                                                                                                          ║
│  ### 7.4 **Builder Pattern** (Optional)                                                                                                                                                  ║
│  For complex configuration:                                                                                                                                                              ║
│  ```rust                                                                                                                                                                                 ║
│  let auth_service = AuthenticationServiceBuilder::new()                                                                                                                                  ║
│      .with_bcrypt_hasher(12)                                                                                                                                                             ║
│      .with_jwt_tokens("secret", 24)                                                                                                                                                      ║
│      .with_postgres_repository(pool)                                                                                                                                                     ║
│      .build();                                                                                                                                                                           ║
│  ```                                                                                                                                                                                     ║
