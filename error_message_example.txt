EXAMPLE: Educational Error Messages for Tool Parsing Failures

When Claude calls Write tool without the 'content' field, it now receives:

{
  "error": "Failed to parse Write tool parameters",
  "details": "missing field `content` at line 1 column 36",
  "required_fields": [
    "file_path",
    "content"
  ],
  "optional_fields": [],
  "example": {
    "file_path": "/absolute/path/to/file.txt",
    "content": "The content to write to the file"
  },
  "help": "The Write tool requires these fields: file_path, content. Please ensure all required fields are provided with the correct types."
}

When Claude calls Bash tool without the 'command' field:

{
  "error": "Failed to parse Bash tool parameters",
  "details": "missing field `command` at line 1 column 17",
  "required_fields": [
    "command"
  ],
  "optional_fields": [
    "timeout",
    "description",
    "run_in_background",
    "dangerouslyDisableSandbox"
  ],
  "example": {
    "command": "ls -la",
    "timeout": 120000,
    "description": "List files in directory"
  },
  "help": "The Bash tool requires these fields: command. Please ensure all required fields are provided with the correct types."
}

When Claude calls Edit tool without 'old_string' and 'new_string':

{
  "error": "Failed to parse Edit tool parameters",
  "details": "missing field `old_string` at line 1 column 36",
  "required_fields": [
    "file_path",
    "old_string",
    "new_string"
  ],
  "optional_fields": [
    "replace_all"
  ],
  "example": {
    "file_path": "/absolute/path/to/file.txt",
    "old_string": "text to replace",
    "new_string": "replacement text",
    "replace_all": false
  },
  "help": "The Edit tool requires these fields: file_path, old_string, new_string. Please ensure all required fields are provided with the correct types."
}

BENEFITS:
1. Claude sees EXACTLY what fields are required
2. Claude sees EXACTLY what fields are optional
3. Claude sees a CONCRETE EXAMPLE of valid input
4. Claude can learn from the error and retry correctly
5. No more repeated failures due to unclear error messages
