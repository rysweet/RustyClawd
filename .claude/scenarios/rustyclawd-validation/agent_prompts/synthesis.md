# Phase 2: Synthesis of Investigation Results

## Objective

Synthesize findings from all Phase 1 workstreams into a unified analysis.

## Inputs

You will receive findings from 5 workstreams:
1. Dependency Analysis
2. Config Analysis
3. Security Analysis
4. Integration Analysis
5. Resource Analysis

## Tasks

1. **Identify Cross-Cutting Themes**
   - Common issues across workstreams
   - Systemic problems
   - Architectural concerns

2. **Prioritize Findings**
   - Critical issues (block release)
   - High priority (fix soon)
   - Medium priority (schedule)
   - Low priority (backlog)

3. **Generate Recommendations**
   - Quick wins (< 1 day)
   - Important improvements (1-3 days)
   - Major enhancements (> 3 days)

## Deliverables

Generate a markdown report with:

1. **Executive Summary**
   - Overall assessment
   - Top 3-5 priorities
   - Validation score (0-100)

2. **Critical Issues**
   - Issues blocking release
   - Security vulnerabilities
   - Breaking bugs

3. **Prioritized Recommendations**
   - Organized by impact and effort
   - Clear action items
   - Estimated effort

4. **Next Steps**
   - What to fix first
   - What to schedule
   - What to defer

## Output Format

```markdown
# Phase 2: Synthesis Report

## Executive Summary
[Overall assessment with validation score]

## Critical Issues
1. [Issue with priority and impact]
2. [Issue with priority and impact]

## High Priority
1. [Issue with priority and impact]
2. [Issue with priority and impact]

## Medium Priority
[List of medium priority issues]

## Low Priority
[List of low priority issues]

## Recommendations
### Quick Wins (< 1 day)
- [Action items]

### Important (1-3 days)
- [Action items]

### Major (> 3 days)
- [Action items]

## Next Steps
[What to do next]
```
