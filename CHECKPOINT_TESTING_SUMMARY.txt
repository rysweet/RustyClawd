DATA STRUCTURES TESTED
================================================================================

FileChange
  - path: String
  - content: String
  - hash: String (for verification)
  - timestamp_ms: u64
  Tests: Creation, hash computation, integrity verification

CheckpointMessage
  - role: String ("user", "assistant", "system")
  - content: String
  - timestamp_ms: u64
  Tests: Role variants, content handling, serialization

SessionState
  - cwd: String (working directory)
  - env: HashMap<String, String> (environment variables)
  - active_contexts: Vec<String> (open files)
  Tests: Creation, env setup, context tracking, serialization

Checkpoint
  - id: String (unique identifier)
  - number: u32 (sequential number)
  - created_at_ms: u64 (creation timestamp)
  - messages: Vec<CheckpointMessage>
  - file_changes: Vec<FileChange>
  - session_state: SessionState
  - description: Option<String>
  Tests: Creation, message recording, file tracking, size calculation

CheckpointHistory
  - session_id: String
  - checkpoints: Vec<Checkpoint>
  - max_checkpoints: usize (retention limit)
  Tests: Recording, retrieval, retention policies, total size

Session
  - id: String
  - current_checkpoint_number: u32
  - history: CheckpointHistory
  - current_state: SessionState
  Tests: Creation, checkpoint creation, restoration, state changes

RestoreScope (Enum)
  - ConversationOnly (message history)
  - CodeOnly (file changes)
  - Both (everything)
  Tests: All three scopes verified with correct behavior
