FEATURES:
=========
✅ Pirate ship ASCII art with crab emoji
✅ Rust-colored theme (orange/brown palette)
✅ Beautiful TUI with ratatui
✅ Real-time message streaming
✅ Keyboard controls:
   - Ctrl+C / Ctrl+D: Exit
   - Enter: Submit message
   - Arrows: Navigate
   - Page Up/Down: Scroll messages
✅ Status bar with pirate theme
✅ All commands work: /exit, /clear, /help, /stats
✅ Shell execution with !<command>

COLOR SCHEME:
=============
- RUST_ORANGE: RGB(222, 165, 132) - Main accent
- RUST_DARK:   RGB(165, 42, 42)   - Borders & structure
- RUST_LIGHT:  RGB(255, 195, 160) - Text highlights
- RUST_BG:     RGB(40, 40, 50)    - Background
- TEXT:        RGB(230, 230, 230) - Message text

USAGE:
======
cargo run --package rustyclawd-cli --bin rusty

The TUI will launch automatically in interactive mode!
