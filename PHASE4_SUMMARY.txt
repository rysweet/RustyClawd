================================================================================
COMMAND LINE INTERFACE
================================================================================

Commands Implemented:
  rusty update
    - Downloads and installs latest version
    - Creates backup before installation
    - Atomic binary replacement
    - Displays restart required message

  rusty update --check
    - Checks for available updates
    - Respects 24-hour interval by default
    - Shows version comparison if update available

  rusty update --check --force
    - Bypasses 24-hour interval
    - Forces immediate check

  rusty update --rollback
    - Restores previous version from backup
    - Atomic replacement
    - Displays restart required message

================================================================================
ARCHITECTURE
================================================================================

Scheduler:
  - Manages 24-hour check intervals
  - Persists state to ~/.rusty/update_check.json
  - Non-blocking startup checks
  - Configurable interval and enable/disable

CLI Integration:
  - Commands enum with Update subcommand
  - Handler routing for check/install/rollback
  - Background task spawning for startup checks
  - User-friendly message formatting

Update Flow:
  1. Check: Query GitHub releases API
  2. Download: Binary to temporary location
  3. Verify: Checksum verification
  4. Backup: Create backup of current binary
  5. Install: Atomic file replacement
  6. Notify: User messages for restart

Rollback Flow:
  1. List: Available backups
  2. Select: Most recent backup
  3. Restore: Atomic file replacement
  4. Notify: User messages for restart
